# NimbusForms

**Renderer-first GDI+ component suite for Delphi VCL.**

NimbusForms is my personal Delphi port of **my own C# WinForms UI library**. Both versions are my projects.

The focus is on custom-drawn controls built around a reusable renderer, not just reskinning standard VCL components.

## Features in development

- Custom GDI+ rendering, themes and DPI-aware layouts
- Themed forms, tabs, menus, toolbars and navigation controls
- Date/time and date-range pickers, color pickers and input controls
- Tree view and virtual list view
- Hex editor using a **piece table**

## Status

**Work in progress — experimental and largely untested.** The Delphi port has been in development for a long time, but progress is irregular. Many details are still unfinished and subject to change.

This repository currently contains **screenshots only**. No source code or binaries are published here.
